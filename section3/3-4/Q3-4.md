# Section 3 Exercise 3-4 | A Realistic Crew: Reading a File + Writing a Report

## Goal

A capstone exercise that combines **a tool (FileReadTool) x collaboration (a 2-agent Crew)**.
Read a scrawled `memo.txt`, turn it into a polished proposal report, and save it to `proposal.md`.

## What you'll learn in this exercise

### Bringing everything together

- 3-2 ... reading a file with a tool
- 2-2 ... passing context from researcher to writer
- 2-4 ... saving with `output_file`

This exercise merges all of that into a single, "realistic" pipeline.

```
Researcher (reads memo.txt and organizes it)
        |context
        v
Writer (turns it into a report) -> saved to proposal.md
```

### Different tools for different roles

- **Researcher**: has `FileReadTool` (because it needs to read the file)
- **Writer**: needs no tool (it just formats the information it's given)

The design trick is to **only equip the agents that actually need a tool**. Not everyone needs to be able to do everything.

## Exercise

Fill in the TODOs in `exercise.py` to complete a realistic Crew. The source material is `memo.txt` (a scrawled new-product idea) in the same folder.

1. Define a researcher Agent that reads `memo.txt` (equipped with `file_tool`)
2. Define a writer Agent that turns it into a report
3. Define a "read and organize" Task and a "format and save" Task (linked with `context`, plus `output_file`)
4. Run the 2-agent, 2-task Crew and generate `proposal.md`

### How to run

```bash
cd exercises/section3/3-4
pip install -r requirements.txt
python exercise.py
# After it finishes, open proposal.md to check the result
```

### Expected behavior (example)

Contents of `proposal.md`:

```markdown
# New Product Proposal: Foldable Electric Kick Scooter

## Features
- Folds down to a bag-sized package, weighs about 7 kg
- Runs about 25 km on a full charge, priced around 80,000 yen

## Target audience
- Urban office workers in their 20s-30s (for commuting)

## Open issues
- Rainy-day usage hasn't been worked out
- Product name is still undecided
```

## Hints

- Only equip the **researcher** with the tool (the writer receives information via context)
- Spell out "read memo.txt" in the `read_task` description
- Attach both `context=[read_task]` and `output_file="proposal.md"` to `write_task`

## Success criteria

- [ ] You used a tool-equipped agent and a tool-free agent appropriately
- [ ] The generated report reflects the content of the memo
- [ ] `proposal.md` was saved as a file

## Common errors

- The report has nothing to do with the memo -> The researcher is missing `tools=[file_tool]`, or context is missing
- `proposal.md` isn't created -> Check that the write_task with `output_file` is included in `tasks`
- `429 RESOURCE_EXHAUSTED` -> Wait a bit and retry

## Challenge (optional)

Add a third agent, an "editor," and extend the pipeline to 3 stages: proofread the writer's draft, then save it (an application of 2-3).

```python
reader = Agent(
    role="Researcher",
    goal="Read a scrawled memo and organize the key points",
    backstory="You are skilled at picking out the important information from a messy memo.",
    tools=[file_tool], llm=llm, verbose=True,
)
writer = Agent(
    role="Business Writer",
    goal="Turn organized information into a readable report",
    backstory="You are a professional at turning bullet-point memos into a well-formatted proposal.",
    llm=llm, verbose=True,
)

read_task = Task(
    description="Read memo.txt and organize the new product idea into 'Features,' 'Target audience,' and 'Open issues.'",
    expected_output="Bullet points organized into 3 categories",
    agent=reader,
)
write_task = Task(
    description="Based on the organized information, create a proposal report (Markdown) with headings.",
    expected_output="# A proposal report (Markdown) with headings",
    agent=writer, context=[read_task], output_file="proposal.md",
)

crew = Crew(
    agents=[reader, writer], tasks=[read_task, write_task],
    process=Process.sequential, verbose=True,
)
result = crew.kickoff()
```
