# Section 3 Exercise 3-2 | Built-in Tools from crewai-tools

## Goal

Equip an agent with the **built-in tool `FileReadTool`** from `crewai-tools`,
and have it read a local memo file (`notes.txt`) and summarize it.

## What you'll learn in this exercise

### Tools are an agent's "hands and feet"

Up to now, agents only "thought and answered."
Giving them a **tool** lets them **act on the outside world** — reading files, running calculations, searching, and more.

CrewAI ships with handy tools right out of the box (`crewai-tools`).

| Tool | What it does | API key |
|---|---|---|
| `FileReadTool` | Reads the contents of a file | Not needed |
| `DirectoryReadTool` | Lists the files in a folder | Not needed |

### How to equip a tool

```python
from crewai_tools import FileReadTool

file_tool = FileReadTool()

researcher = Agent(
    role="Meeting Notes Analyst",
    goal="Read a memo file and organize the key points",
    backstory="...",
    tools=[file_tool],   # <- pass the tool here
    llm=llm,
)
```

Passing `tools=[file_tool]` means this agent **decides on its own when it needs to go read the file**.
All you have to do is instruct it: "read notes.txt and summarize it."

## Hints

- `FileReadTool()` takes no arguments (the file to read is specified in the description)
- Spell out the file name you want read (`notes.txt`) in the description
- If you forget to pass the tool, the agent can't read the file and will just make up an answer

## Success criteria

- [ ] You equipped the agent with `FileReadTool`
- [ ] The summary was based on the actual content of `notes.txt`
- [ ] You can explain that "having a tool lets an agent work with external data"

## Common errors

- The content doesn't match the facts (the agent is guessing) -> You forgot to pass `tools=[file_tool]`
- `FileNotFoundError` -> Check that you're running the script from the same folder as `notes.txt`
- `429 RESOURCE_EXHAUSTED` -> Wait a bit and retry

researcher = Agent(
    role="Meeting Notes Analyst",

    verbose=True,
)

    expected_output="A 3-bullet-point summary",
