# Section 2 Exercise 2-2 | A 2-agent Crew: researcher + writer

## Goal

Coordinate **two agents** with different roles through a `sequential` process.
Experience how, using `context`, **the output from an earlier stage flows into the next stage**.

## What you'll learn in this exercise

### Why split up roles

If you make one agent do everything — "research it, then write it" — the instructions balloon and the quality becomes inconsistent.
Splitting the work between **someone who researches (the researcher)** and **someone who writes (the writer)** lets each one focus on their own job, improving both quality and debuggability.

```
Researcher: researches the key points  ->  Writer: writes an introduction based on that
```

### Connecting tasks with `context`

If you pass an earlier task into a Task's `context`, that task's **output is carried over as input**.

```python
write_task = Task(
    description="Based on the research results, write an introduction.",
    expected_output="An ~200-word introduction",
    agent=writer,
    context=[research_task],   # <- research_task's result flows in here
)
```

### Running in order with `Process.sequential`

```python
crew = Crew(
    agents=[researcher, writer],
    tasks=[research_task, write_task],   # run in this order
    process=Process.sequential,
    verbose=True,
)
```

## Hints

- Pass both `agents` and `tasks` as **lists** (`[researcher, writer]`)
- If you forget `context=[research_task]`, the writer ends up writing without knowing what the researcher found
- The final deliverable (`result`) is **the output of the last task**

## Success criteria

- [ ] You combined two agents into a single Crew

## Common errors

- `NameError: writer` → The writer Agent definition (TODO 1) is still commented out
- The introduction has nothing to do with the research → `context=[research_task]` is missing
- `429 RESOURCE_EXHAUSTED` → Now calling out to 2 agents, which uses more of your quota. Wait a bit and try again

writer = Agent(
    role="Writer",
    goal="Write an easy-to-understand introduction based on the research results",
    backstory="You are a writer who is great at conveying difficult content in a simple, approachable way.",
    llm=llm,
    verbose=True,
)

write_task = Task(
    description="Based on the research results, write an ~200-word introduction to {topic}.",
    expected_output="An ~200-word introduction",
    agent=writer,
    context=[research_task],
)

crew = Crew(
    agents=[researcher, writer],
    tasks=[research_task, write_task],
    process=Process.sequential,
    verbose=True,
)

result = crew.kickoff(inputs={"topic": "deep-sea creatures"})

print("\n=== Final deliverable (introduction) ===")
print(result)
