## Goal

Use a Task's `output_file` to **save the Crew's output as a Markdown file**.
Experience "the output stays behind after running" — one step closer to a real, practical app.

## What you'll learn in this exercise

### "Keeping" the output

So far, results were only shown on screen with `print`. In real-world work, you usually want to keep the output as a file.
Just specify `output_file` on a Task, and that Task's output is automatically written to a file.

```python
edit_task = Task(
    description="Finish the writer's introduction into a Markdown article (with a heading).",
    expected_output="# A Markdown article with a heading",
    agent=editor,
    context=[write_task],
    output_file="report.md",   # <- this alone saves it to report.md
)
```

### Which Task should get it

The general rule is to attach it to **the last Task** (the one that produces the final deliverable).
Here, we attach it to the editor's `edit_task`, saving the finished article to `report.md`.

## Success criteria

- [ ] You specified `output_file`
- [ ] `report.md` was generated after running
- [ ] Its contents are a Markdown article with a heading

## Common errors

- No file gets created -> Check that the Task with `output_file` is actually being run (i.e. included in the `tasks` list)
- Contents aren't Markdown -> Write "Markdown format" / "with a heading" in `expected_output`
- `429 RESOURCE_EXHAUSTED` -> This calls 3 agents. Wait a bit and retry
