# Section 2 Exercise 2-3 | Adding a reviewer to make it a 3-agent Crew

## Goal

Add an **"editor" Agent that you define yourself** to the 2-agent Crew from 2-2, adding one more quality-check stage.
Experience how much the deliverable improves just by adding a single agent.

## What you'll learn in this exercise

### Adding a stage = adding quality

Just as in real-world production, **separating the person who writes from the person who fixes** improves quality.

```
Researcher (researches) -> Writer (writes) -> Editor (fixes)
```

The editor is a specialist in "proofreading and polishing." They take the writer's draft and turn it into a final draft by fixing typos, wordiness, and unclear passages.

### All you're adding is 1 Agent and 1 Task

At the end of the 2-2 flow, you just connect a Task that receives the earlier stage (the writer) via `context`.

```python
edit_task = Task(
    description="Proofread the writer's introduction and turn it into a final draft.",
    expected_output="The proofread final draft",
    agent=editor,
    context=[write_task],   # <- receives the writer's output
)
```

```python
editor = Agent(
    role="Editor",
    goal="Proofread the text and turn it into a polished, accurate final draft",
    backstory="You are a veteran editor with a sharp eye for detail. Nothing gets past you — typos or awkward phrasing.",
    llm=llm, verbose=True,
)

edit_task = Task(
    description="Proofread the writer's introduction and polish it into a more readable, accurate final draft.",
    expected_output="The proofread final draft",
    agent=editor,
    context=[write_task],
)

crew = Crew(
    agents=[researcher, writer, editor],
    tasks=[research_task, write_task, edit_task],
    process=Process.sequential,
    verbose=True,
)
result = crew.kickoff(inputs={"topic": "the science of sleep"})

print("\n=== Final draft (polished by the editor) ===")
print(result)
```
