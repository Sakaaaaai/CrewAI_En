# Section 4 Exercise 4-2 | Redefining Agents / Tasks with YAML

## Goal

## What you'll learn in this exercise

### Why split things out into YAML

So far, you've written `role` and `description` directly in Python code.
In real-world projects, it's standard practice to move that content out into **YAML files (configuration)**.

| Benefit of separating them | Explanation |
|---|---|
| Enables collaboration with non-engineers | A planner can edit just the YAML text |
| Improves clarity | "Process flow" and "agent content" are organized into separate files |
| The official standard form | This is also the shape that `crewai create` generates (covered in 4-3) |

### The shape of the config files

`config/agents.yaml` (role definitions):

```yaml
researcher:
  role: Researcher
  goal: "Accurately research the key points of {topic}"
  backstory: You are a research expert who is great at quickly spotting the key points.
```

`config/tasks.yaml` (job definitions):

```yaml
research_task:
  description: "Research 3 key points about {topic}."
  expected_output: Research results as 3 bullet points
```

### Loading the YAML and assembling it

Passing the dict you read from YAML into `Agent(config=...)` / `Task(config=...)` builds the object from that content.

```python
researcher = Agent(config=agents_config["researcher"], llm=llm)
research_task = Task(config=tasks_config["research_task"], agent=researcher)
```

> `agent` and `context` (data hand-off) are part of the "flow," so they're specified on the Python side. Roles and wording live in YAML.

## Common errors

- `FileNotFoundError: config/agents.yaml` → Check that you're running from directly inside the `4-2` folder
- Garbled text (mojibake) → Add `open(..., encoding="utf-8")`
- `KeyError` → Check that the YAML key names (e.g. `researcher`) match the names referenced in Python

```python
researcher = Agent(config=agents_config["researcher"], llm=llm, verbose=True)
writer = Agent(config=agents_config["writer"], llm=llm, verbose=True)

research_task = Task(config=tasks_config["research_task"], agent=researcher)
write_task = Task(config=tasks_config["write_task"], agent=writer, context=[research_task])

crew = Crew(
    agents=[researcher, writer],
    tasks=[research_task, write_task],
    process=Process.sequential,
    verbose=True,
)
result = crew.kickoff(inputs={"topic": "renewable energy"})

print("\n=== Article ===")
print(result)
```
