# Section 4 Exercise 4-3 | The @CrewBase Decorator

## Goal

Rewrite the YAML-based Crew from 4-2 into **class form using `@CrewBase`**.
This is the **official, real-world standard style** generated by `crewai create`. Learn to recognize this shape when you read code in future documentation and samples.

## What you'll learn in this exercise

### Bundling a Crew into a class

Inside a class decorated with `@CrewBase`, you line up methods decorated with `@agent` / `@task` / `@crew`.
**CrewAI automatically handles** loading the YAML and collecting the agents and tasks.

```python
from crewai.project import CrewBase, agent, task, crew

@CrewBase
class ContentCrew:
    agents_config = "config/agents.yaml"   # loaded automatically
    tasks_config = "config/tasks.yaml"

    @agent
    def researcher(self) -> Agent:
        return Agent(config=self.agents_config["researcher"], llm=self.llm)

    @task
    def research_task(self) -> Task:
        return Task(config=self.tasks_config["research_task"])

    @crew
    def crew(self) -> Crew:
        return Crew(agents=self.agents, tasks=self.tasks, process=Process.sequential)
```

### `self.agents` and `self.tasks` are collected automatically

Methods decorated with `@agent` / `@task` are automatically gathered into a list by CrewAI and placed into `self.agents` / `self.tasks`.
That's why inside `@crew` you only need to write **`agents=self.agents`** (no need to line them up by hand).

### How to run

```python
result = ContentCrew().crew().kickoff(inputs={"topic": "space elevators"})
```

The flow is: instantiate with `ContentCrew()` -> get the Crew with `.crew()` -> run it with `.kickoff()`.

## Common errors

- `KeyError: 'researcher'` → Check that the YAML key names in `config/` match the names referenced in code
- `FileNotFoundError` → Check that `config/agents.yaml` is in a `config/` folder at the same level as exercise.py (CrewBase looks relative to the location of the file where the class is defined)
- `agents` is empty inside `@crew` → Check that you didn't forget to add the `@agent` decorator
