# Section 6 Exercise 6-3 | Wiring in the writing Crew

## Goal

Connect the section 2 writing Crew to the **"approved" route** of the Flow skeleton you built in 6-2.
The Flow (control tower) creates the outline, and the Crew (work team) writes the article following it — this is the integration in action.

## What you'll learn in this exercise

### Putting "substance" into the skeleton

In 6-2, the approved route was just a placeholder message. Here you'll connect the real writing team.

```
Generate outline (Flow) → approve → writing Crew (researcher → writer → editor)
```

The function `build_writing_crew()`, which builds the 3-agent writing Crew, is already provided. All you need to do is **call it from the approved route**.

### Passing the Flow's information to the Crew

The key point is passing **both** pieces of information the Flow holds (`topic` and `outline`) **to the Crew**.
This makes the Crew write the article "following the outline the Flow created."

```python
result = crew.kickoff(inputs={
    "topic": self.state.topic,
    "outline": self.state.outline,   # pass the outline too
})
self.state.article = str(result)
```

The writer's Task is written to receive `{outline}`, so the outline is reflected directly in the writing.

## Exercise

Fill in the TODOs in `exercise.py`. `build_writing_crew()` and the Flow skeleton (equivalent to 6-2) are already provided.

1. Implement the `write_article` step under `@listen("approved")`
2. Build the Crew with `build_writing_crew()`, and `kickoff` it passing both `topic` and `outline` in `inputs`
3. Save the result into `self.state.article` and return it

## Hints

- Just calling `build_writing_crew()` gets you a ready-to-use 3-agent Crew
- Pass **both** `topic` and `outline` in `inputs` (passing only one means the outline won't be reflected)
- Wrap `kickoff`'s result with `str(result)` before saving it into state

## Success criteria

- [ ] You called the writing Crew from the approved route
- [ ] The Flow's outline is reflected in the article
- [ ] Flow × Crew integration produced one complete article

## Common errors

- The outline isn't reflected in the article → you forgot to pass `outline` in `inputs`
- `KeyError: 'outline'` → check that the key name in `inputs` matches `{outline}` inside the Task
- `429 RESOURCE_EXHAUSTED` → outline generation plus a 3-agent Crew means a lot of calls. Wait a bit and retry

## Challenge (optional)

Change `self.state.topic` to a different topic and run it again, to confirm you can produce an end-to-end article on a different subject, from outline all the way to the finished article.

## Model answer

<details>
<summary>Show the solution code</summary>

```python
@listen("approved")
def write_article(self):
    crew = build_writing_crew()
    result = crew.kickoff(inputs={"topic": self.state.topic, "outline": self.state.outline})
    self.state.article = str(result)
    return self.state.article
```
