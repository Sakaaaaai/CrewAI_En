# Section 5 Exercise 5-4 | Branching with @router

## Goal

Use `@router` to **branch processing based on an LLM's judgment**.
Build a "support reply Flow" that detects the language of the input text and routes it to a Japanese route if it's Japanese, or an English route if it's English.

## What you'll learn in this exercise

### Flow's true strength: conditional branching

Crews are great at "collaboration," but control like **"if X, do A; otherwise do B"** is where Flows shine.
`@router` is at the center of this.

### How `@router` works

Whatever **string** a method decorated with `@router` returns is picked up by `@listen("that string")`.

```python
@router(receive)
def detect_language(self):
    # ... judgment ...
    return "japanese"        # <- this string decides the route

@listen("japanese")          # runs when "japanese" is returned
def reply_japanese(self):
    ...

@listen("english")           # runs when "english" is returned
def reply_english(self):
    ...
```

In other words, **the router's return value acts as a switch**, and only the matching `@listen("...")` runs.

### Letting the LLM make the judgment

"Small, smart judgments" like language detection can be delegated to the LLM.

```python
answer = llm.call(f"If the following sentence is Japanese, answer only 'japanese'; if it's English, answer only 'english'.\nSentence: {self.state.text}")
```

## Hints

- The argument to `@router(receive)` is the name of the step method that runs before the judgment (`receive`)
- The argument to `@listen("japanese")` is a **string** (it must match the value the router returns)
- The judgment is more stable if you branch based on whether "japan" appears in the response from `llm.call(...)`

## Common errors

- Both routes run, or neither runs → check that the router's return value matches the string in `@listen("...")`
- `AttributeError: state` → check the type parameter `Flow[ReviewState]`
- `429 RESOURCE_EXHAUSTED` → this calls the LLM twice (judgment + reply). Wait a bit and retry

```python
@router(receive)
def detect_language(self):
    answer = llm.call(
        f"If the following sentence is Japanese, answer only 'japanese'; if it's English, answer only 'english'.\nSentence: {self.state.text}"
    )
    lang = "japanese" if "japan" in answer.lower() else "english"
    print("Detected:", lang)
    return lang

@listen("japanese")
def reply_japanese(self):
    self.state.reply = llm.call(f"Reply politely in Japanese to this review: {self.state.text}")
    return self.state.reply

@listen("english")
def reply_english(self):
    self.state.reply = llm.call(f"Reply politely in English to this review: {self.state.text}")
    return self.state.reply
```
