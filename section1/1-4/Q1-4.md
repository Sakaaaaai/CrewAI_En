# Section 1 Exercise 1-4 | A mini Crew with 1 Agent, 1 Task

## Goal

Bring the Agent and Task you've built so far together into a **Crew** and run it with `kickoff`.
Then use `inputs` to **pass a variable ({topic}) in from outside**, so you can reuse the same code any number of times without editing it.

## What you'll learn in this exercise

### A Crew is "the team and the place work happens"

All three of CrewAI's core elements come together here.

```
Agent (worker) + Task (work) -> Crew (team) -> kickoff (execution)
```

```python
from crewai import Crew, Process

crew = Crew(
    agents=[researcher],
    tasks=[task],
    process=Process.sequential,   # run them in order, top to bottom
    verbose=True,
)
result = crew.kickoff()
```

### Plugging in variables with `inputs`

If you write a placeholder like `{topic}` inside a Task's `description`,
you can substitute in an actual value via `kickoff(inputs=...)`.

```python
task = Task(
    description="Summarize the key points of {topic} into 3 bullet points for beginners.",
    expected_output="A summary report with 3 bullet points",
    agent=researcher,
)
...
result = crew.kickoff(inputs={"topic": "space travel"})
```

This lets you **run the same Crew any number of times, changing only the topic** (a huge boost to reusability).

## Common errors

- `KeyError: 'topic'` → The `{topic}` in `description` doesn't match the key name in `inputs`
- `NameError: crew` → The Crew definition (TODO 2) is still commented out
- `429 RESOURCE_EXHAUSTED` → Wait a bit and try again
